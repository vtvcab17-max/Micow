Thư viện

Mọi bài đã tạo nằm trên máy bạn (thư mục ~/.micow/library). Tải WAV, MP3, stem, MIDI kèm lời, hoặc .lrc để làm video lời bài hát trong Bravin.

Mô hình

Micow chạy hoàn toàn trên máy bạn. Micow Beat có sẵn; cài thêm ACE-Step 1.5 để có giọng hát thật, hoặc huấn luyện Micow-LM của riêng bạn.

Máy của bạn
Huấn luyện Micow-LMkiến trúc suy ngược từ Suno

Codec RVQ biến âm thanh thành token → transformer tự hồi quy sinh token theo phong cách, lời (byte UTF-8) và clip tham chiếu. Chạy các lệnh sau trong thư mục cài Micow (GPU NVIDIA khuyến nghị; chỉ dùng nhạc bạn có quyền):

micow data synth --out data --n 200            # dữ liệu khởi động bằng Micow Beat
micow train codec    --data data/manifest.jsonl --out ~/.micow/models/micow-lm/cua-toi/codec.pt
micow train tokenize --data data/manifest.jsonl --codec ~/.micow/models/micow-lm/cua-toi/codec.pt --out data/tokens
micow train lm       --tokens data/tokens --out ~/.micow/models/micow-lm/cua-toi/lm.pt --preset small

Xem docs/HUAN_LUYEN.md để biết cách chuẩn bị dữ liệu thật (manifest JSONL + LRC).

Tải Micow về máy

Micow chạy trên máy của bạn, miễn phí, không giới hạn lượt tải nhạc. Trang web này chỉ là giao diện: cài Micow một lần, mở Micow, rồi quay lại đây bấm Thử lại.

Cách 1 · một lệnh. Mở PowerShell, dán lệnh này, Enter (tự cài Python nếu thiếu, tạo biểu tượng Micow trên Desktop):

irm https://raw.githubusercontent.com/vtvcab17-max/Micow/HEAD/scripts/get.ps1 | iex

Cách 2 · tải tệp. Tải gói .zip, giải nén, bấm đúp Cai dat Micow.bat rồi Mo Micow.bat.

Mở Terminal, dán lệnh này (cần Python 3.10+: brew install python@3.12):

curl -fsSL https://raw.githubusercontent.com/vtvcab17-max/Micow/HEAD/scripts/get.sh | bash

Xong thì chạy micow serve --open. Máy chip M dùng GPU Apple cho ACE-Step / Micow-LM.

Dán lệnh này vào terminal (Ubuntu: sudo apt install python3 python3-venv curl trước):

curl -fsSL https://raw.githubusercontent.com/vtvcab17-max/Micow/HEAD/scripts/get.sh | bash

Xong thì chạy micow serve --open. Có card NVIDIA: thêm | bash -s -- --with-torch để huấn luyện bằng GPU.
